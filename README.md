# Avatars by Muses

Командный учебный проект (Московский Политех, 2025): веб-сервис для создания 3D-аватаров для метавселенных. Партнёр проекта — компания Texel. Команда MetaMuses — 7 студентов, капитан — Мария Андрианова.

Итог проекта — прототип сайта, в котором пользователь собирает аватар (внешность, одежда, аксессуары) и получает ссылку на готовую 3D-модель. Работа сервиса показана в [видео-обзоре](demo/Видео-обзор.mp4).

## Моя роль

Капитан команды:

- распределяла задачи по спринтам и писала подробные задания участникам
- следила за сроками и качеством, возвращала работы на доработку
- ввела прозрачную систему учёта вклада каждого участника
- формировала и расширяла команду
- отчитывалась перед куратором проекта

## Структура

- `demo/` — видео-обзор сервиса (2 минуты)
- `project/` — документы проекта: бизнес-план, исследование целевой аудитории, анализ опроса пользователей, таблица конкурентов, SWOT-анализ, питч-презентация, проблема цифровой идентичности, техническое исследование, обзор Roblox
- `research/` — исследования технологий: инструменты для 3D-моделирования и генерации аватаров, нейросети Hunyuan и Trellis, StyleGAN2 и StyleGAN3, совместимость SMPL-X с Blender, форматы экспорта 3D-моделей, языки программирования, описание первого прототипа
- `roadmap/` — дорожная карта проекта по спринтам: 19 задач в 4 блоках (подготовка, планирование и анализ, разработка и тестирование, маркетинг и финализация)

## Прототип

Одностраничный сайт на HTML и JavaScript. Редактор аватаров встроен через iframe сервиса Ready Player Me, страница слушает события редактора и показывает ссылку на экспортированный аватар. Собственная модель генерации аватаров в прототипе не реализована.

Сервис Ready Player Me прекратил работу 31 января 2026 года, поэтому запустить прототип сейчас нельзя. Как работало решение, показано в видео-обзоре.
